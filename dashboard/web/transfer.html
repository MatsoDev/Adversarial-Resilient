Four realism requirements

Policy projection checks numeric bounds, integer values and immutable coordinates only.
Coupled structural consistency
Not established. Derived features are not recomputed together.
Executable realizability
Not established. No authorized isolated-lab PE demonstration.
Preserved behavior
Not established. No executable was modified or run.

Owner authorization is not technical Security review. A feature edit proves none of the other three properties.

Scope and missing evidence

HopSkipJump and ZOO: not implemented, not run. CICIDS: inactive; no trained IDS evidence. Problem-space lab: not authorized, not run. M1 and frozen-benchmark acceptance remain separate.

Transfer ASR uses target-clean-correct rows, not source successes. Conditional transfer additionally requires both models initially correct and source attack success. Preexisting errors are never attack successes.

Malware evasion counts initially detected malicious rows made benign. False-positive induction counts initially correct benign rows made malicious. Empty denominators are unavailable, not zero.

Shared training data and preprocessing are attacker knowledge assumptions, not a strict unknown-data black-box scenario.

Can an AI security guard be fooled?

We train AI to tell benign and malicious file features apart. Then we deliberately challenge its decisions to find weaknesses before relying on it.

The questions behind the project

What is EMBER, and what is a sample?

EMBER contains numeric descriptions extracted from Windows programs, with known labels where available. A sample here is one description, like a file's information card. We do not run the original program.

Who would use this, and why?

Security researchers and teams building AI detectors can use these tests to find weaknesses and compare model versions before deployment. This research prototype is not a complete antivirus product.

Did we actually change a malware file?

No. This experiment changes recorded feature values only. A decision change does not prove that a valid executable could be modified in the same way.

Does one fooled example prove the whole model is bad?

No. A case explains what happened once. The larger experiment measures how often it happened, under the exact model, sample selection and constraints shown.

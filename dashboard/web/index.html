GRADUATION RESEARCH / ADVERSARIAL MACHINE LEARNING

Adversarial resilience in malware detection

This project studies machine-learning malware detectors using numeric features extracted from files. Adversarial examples are deliberately modified inputs used to test whether a model's decision changes. The recorded experiments evaluate these changes in feature space, not on executable files.

01 / MODEL

    Dataset and interpretation

    EMBER feature records

    EMBER contains numeric descriptions extracted from Windows programs, with known labels where available. Each sample is one feature record; the original program is not executed.

    Research use and scope

    These tests help researchers assess detector decisions under specified conditions. The prototype is not a complete antivirus product.

    Limits of an individual case

    A selected case illustrates one outcome. Aggregate results describe the evaluated cohort under the specified model, sample selection and constraints; neither establishes a valid executable modification.

    Evaluation objective

    Clean accuracy alone does not establish robustness. This study measures attack-induced errors; future work will evaluate defenses and their effect on ordinary performance.

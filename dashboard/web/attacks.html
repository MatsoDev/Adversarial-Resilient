Read the numbers

Accuracy: correct decisions ÷ all evaluated rows. Clean and attacked scores use the same rows.

ASR: originally correct decisions made incorrect ÷ originally correct decisions. Both benign and malicious rows are included; this is untargeted error induction, not a malware-only evasion rate. An empty denominator is unavailable.

Perturbations: mean L0 (changed coordinates above 10⁻⁶), L2 and L∞ across all evaluated rows, in signed-log1p standardized model coordinates. Epsilon is not a percentage or a raw byte budget.

Constraints: bounds, immutable masks and integer counts are feature-space approximations. They do not establish a valid executable. CW-L2 is projected after generation and is not a constrained optimum.

Cross-check: CleverHans is an independent implementation; matching metrics alone do not prove equivalent attacks. Missing checks remain “Not run”. No experiments run from this page.
